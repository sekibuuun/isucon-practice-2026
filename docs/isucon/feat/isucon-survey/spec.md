# 設計メモ

## 目的・制約

- ブランチ：feat/isucon-survey。起点：develop d256c0c。
- 対象：リポジトリ内のスキルと利用資料。実環境操作・公開範囲変更・pushは対象外。
- ユーザー合意：surveyで短時間の横断調査を行い、優先度順の「順位・ID・対象・原因」を提示。ユーザーが選んだ一件をworkflowで改善する。
- 調査ID別の一覧・根拠・履歴と、ブランチ別改善記録を関連付ける。

## 反復 001：設計

- surveyを新設し、計測・実行制御は既存スキルを参照する。自動選定・性能変更はしない。
- workflowから全体の対象選定を外し、選択された対象の原因検証・一候補ずつの実装・採否判断を維持する。
- 採否判断・反映／復旧後に一覧を更新。解消確認済みの項目を履歴へ移し、残りの原因・順位は根拠がある範囲だけ更新する。
- 次の対象や全体再調査は自動実行せず、継続方法の選択肢を終了報告へ追加しない。
- 受け入れ条件：7スキルの構文・UI設定、リンク、差分検査、運用シナリオ確認。
- 性能計測は対象外。競技ルール本文の変更や適合性評価は行わない。
