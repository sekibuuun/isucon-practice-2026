## 反復 001：スキルの作業単位と判断ゲート

- ブランチ：`docs/isucon-one-bottleneck`。developの `6108421` から作成。
- 目的：一回のワークフローで一つのボトルネックを扱い、一候補ずつ試して修正前後のスコアを人間へ提示する。
- 採用時は正式反映して終了。却下時は候補だけ戻し、同じボトルネックの候補選定へ戻る。再計測時は同じ候補を測り直す。
- トークン削減：同じ作業中の共通資料再読込を避け、詳細資料とログ出力を必要な部分に限る。必要な計測・検証・反映確認・ベンチのコマンドと試行は維持する。
- 対象：リポジトリ内のスキル、共通資料、テンプレート、AGENTS.md、README.md。
- 対象外：ISUCONアプリの性能実装、実環境の構築・反映・ベンチ、push、公開範囲の変更。
- 受け入れ条件：相対リンクと差分が正しく、採用・却下・再計測・無効ベンチ・mustの机上ケースで停止と再開先が一貫すること。
