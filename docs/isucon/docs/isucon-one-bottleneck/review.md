# セルフレビュー

## 反復 001：文書変更

- 対象：スキル、共通資料、記録テンプレート、AGENTS.md、README.mdの差分。
- 観点：一つのボトルネック、候補を一つずつ実装、人間の判断待ち、却下後の再選定、コマンド維持、ルール・永続性の保持。
- 静的確認：`git diff --check` 成功。変更した相対参照は既存ファイルを指す。
- 採用：人間の判断後に正式反映し、別のボトルネックへ進まず終了。
- 却下：候補のみ取り消して復旧検証し、同じボトルネックの別候補を一つ選ぶ。比較基準が変われば再計測。
- 再計測・無効ベンチ：同じ候補の条件と結果を確認し、新候補を実装しない。
- must：採否と分けて修正・保持し、ルール・仕様・永続性を維持。
- 未解消must：なし。トークン削減の実効値は次回スキル利用時に確認する。
- 実環境での有効スコアと再起動追試：文書変更のため対象外。
