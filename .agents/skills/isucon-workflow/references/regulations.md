# ISUCON2026競技ルール

作業開始時に [公式レギュレーション](https://isucon.net/archives/59966826.html) の最新版を確認する。

## 開始時

練習か本番か、対象大会を確認する。本番では最新公式本文・当日マニュアル・ポータル・運営アナウンスを確認し、参照元・日時・許可サーバー・保守コマンド・採点方法をspecに残す。ソフトウェア事項は当日マニュアル優先。不明な行為は許可を推測せず、その部分を止めてユーザーに運営への確認を依頼する。質問を勝手に送信しない。

## 必須条件

- アクセス先URIを維持する。サーバー生成ID等は指定の文字種を守る。
- HTML DOM・JSON等のレスポンス構造を維持する。空白変更も表示に影響しない範囲に限る。
- JavaScript/CSS、画像・動画等の内容を変更しない。圧縮・配信経路の変更も復元後の内容と仕様を保つ。認証を静的配信で迂回しない。
- 保守コマンドの互換性と再起動後の正常動作を維持する。ベンチ中の書き込みデータは再起動後も取得可能にする。
- 複数台の再起動順は保証されない。依存先復旧・起動再試行・冷えたキャッシュでの動作を確認する。

役割、スキーマ、インデックス、DB製品、言語、キャッシュ、遅延書き込みの変更、AIによる開発は許可例に含まれる。ただし正当性・永続性・当日の制約を満たすこと。遅延書き込みは受理済みデータの喪失を許すものではない。

## 外部資源・公開範囲

ベンチ中のサービス処理・保存を許可外サーバーへ委譲しない。外部CDN・DB・キャッシュ・GitHub runnerでのサービス処理を高速化策に使わない。PC・外部サーバーによるモニタリング・テスト・開発とAI開発は許可されているが、サービス処理の外部依存へ拡張しない。

本番ベンチは正式な起動方法だけを利用する。ベンチマーカーへのログイン試行、他チームのサーバーへのアクセス、妨害・結託をしない。

競技終了まで問題内容・計測方法等を公開・他チームへ共有しない。競技時間中にチーム外の人物と問題のやりとりをしない。運営の公開情報とログイン必須のポータル情報を区別する。

本プロジェクトはリポジトリ・CIログ・成果物をチーム限定・非公開運用とする。競技内容をpushする前に実際の公開範囲を確認する。公開Issue・検索クエリにも非公開内容を含めない。AIは認められた開発用途で扱う。

## 終了時

追試は再起動を含み、正常完了と競技スコアに近い結果の再現が求められる。正式な操作経路で再起動、データ保持、保守・初期化、起動順を確認し、結果とSHAを記録する。高い数値だけをルール適合の証明にしない。
